# 🔐 Password Generator

A clean and simple **Java Password Generator** that creates strong, secure passwords with customizable character sets and lengths.

---

## ✨ Features

- ✅ Customizable password length
- 🔠 Includes uppercase & lowercase letters
- 🔢 Adds digits and special characters
- ⚡ Fast, lightweight, and beginner-friendly
